# 도표 근거 풀이 SFT 파일럿

목적은 이미지의 위치·연결·기호를 읽고 그에 맞는 규칙을 적용하는 학습 예시가 기존
Qwen3-VL-4B의 정확도를 높이는지 시험하는 것이다. 기존 CoT, 개선된 파서와 MMMU 평가
설정을 유지한다. 망각 지표는 사용하지 않는다. 현재 19개는 효과 크기를 정밀 추정하기
위한 규모가 아니라 주석·학습·평가를 실제로 연결하는 첫 파일럿이다.

## 데이터와 주석

- 원본: BMMR **train**, revision `e07b24f9758b6421c8b92cc5cfb0de26dd722b5a`.
- 이미지 38개를 이번 표적 검수에서 직접 확인했다. 불완전 입력·답 표시·모호한 보기 등
  14개를 보류하고 24개에 새 주석을 작성했다. 전체 BMMR의 품질 비율을 추정한 것은 아니다.
- 19개 학습, 5개 외부 진단. 문항별 배정은 학생 모델 추론 전에 고정했다.
- 진단용의 원래 source split도 train이지만, 실험에서는 학습에서 제외한다.
  원·강체변환·누적 차트 그룹 5개를 진단용으로 두었으므로 이 점수는 새로운 문제군으로의
  작은 전이 검사이다. 학습 항목과 동일한 능력 분포의 무작위 검증셋은 아니다.
- 학습 항목: 직각삼각형·쌍곡선 그래프·유향 그래프·평행사변형 넓이·극좌표·정전기
  도표·닮음·평행선·겹친 정사각형·합동 표시·기계계·운동 그래프.
- MMMU validation 900개 및 BMMR 평가 데이터에 대해 기존 텍스트 중복 플래그,
  이미지 byte/pixel SHA256, dHash 근접 검사를 적용했다. 선택한 이미지 모두 통과했다.
  검사 통과는 의미상 중복까지 완전히 없다는 증명이 아니다. 출판사별 원문 출처 ID가
  없어 출처 전체 단위 분리는 인증하지 못하며, 알려진 문제군은 같은 쪽에 두었다.
- 평가 문항의 이미지·질문·답·풀이 및 변형 문항은 학습 예시에 사용하지 않았다.

새 주석은 `시각 근거 → 적용 규칙 → 짧은 풀이 → Answer: X` 구조다.
현재 대화의 Codex가 원본 이미지를 보고 풀이를 작성하고 검산했으며, 독립적인 다른
모델이나 사람의 검수는 아니다. 정확한 백엔드 모델 ID는 확인되지 않아 기록하지 않았다.
도구로 계산 가능한 유향 최단거리·좌표변환·넓이 등은 별도 계산으로 확인했다.

원래 답변과 비교했을 때 24개 중 4개는 최종 답이 달랐다. 재확인 결과:

| 원본 ID | 구분 | 기존 답 → 검수 답 | 차이 |
|---|---|---|---|
| 130215501 | train | C → A | 식의 초깃값은 2라면서 실제로는 원점에서 시작하는 C를 선택 |
| 146516885 | train | E → C | 왼쪽 끝의 점 P를 위쪽 점으로 가정해 가속도 방향을 잘못 선택 |
| 138068443 | train | E → D | 그림이 있는데 없다고 서술하며 판단 불가 선택 |
| 98096888 | diagnostic | D → B | 실제 격자의 회전 중심 Q 대신 근거 없는 O를 가정하고 P 선택 |

이 수치는 교사 주석을 검수한 표본의 결과이며, 학생 모델이 이 네 문제를 틀렸다는 뜻은 아니다.
각 판단과 제외 사유는 [annotations.json](annotations.json)에 보존했다.

학생의 학습 전 seed 0 추론에서는 **19개 중 14개 정답**, 5개 오답(그중 1개 출력 잘림)이었다.
오답은 쌍곡선 보기 대응, 유향 그래프의 화살표 방향, 비균일 전기장 방향, 삼각형 변 길이,
합동 증명의 각도 표시 해석에서 나왔다. 이 분석 후 학습 집합을 바꾸지는 않았다.
[학습 전 결과 및 오류 관찰](base_train_summary.json)은 이 선별된 train 집합의 결과이며
일반화 성능이나 전체 MMMU 오류 분포를 뜻하지 않는다.

## 사전에 고정한 비교

| 조건 | 학습 목표 | 나머지 설정 |
|---|---|---|
| base | 학습 없음 | 기존 기준 모델 |
| answer | 검수 정답의 `Answer: X`만 | 아래 공통 설정 |
| rationale | 동일 정답 + 시각 근거·적용 규칙·풀이 | 아래 공통 설정 |

기존 BMMR 답변은 이 표본에서 모두 중국어이고 일부 정답도 잘못되어 있다. 이를 그대로
대조군으로 쓰면 언어·정답 교정·풀이 품질이 동시에 달라진다. 그래서 첫 파일럿은 같은
검수 정답을 사용하는 **정답만 vs 풀이 포함** 비교로 바꿨다. 기존 풀이 SFT는 실행하지 않는다.

- 동일한 pinned base checkpoint, 학습 seed 0, 19개 항목, 동일한 노출 순서.
- 8 epochs, 총 152회 예시 노출, microbatch 1, gradient accumulation 4, 총 38 optimizer steps.
- LoRA rank 16, alpha 32, dropout 0, learning rate `5e-5`, warmup 4 steps, AdamW, weight decay 0.
- 언어 모델의 attention/MLP projection만 학습한다. 시각 인코더와 나머지 기본 가중치는 고정한다.
- 이미지 예산은 기존 평가와 같다. assistant 응답 토큰에만 손실을 적용한다.
  6,144 토큰을 넘으면 조용히 자르지 않고 중단한다.
- 풀이 조건은 정답만 조건보다 감독 토큰이 많다. 동일한 총 감독 토큰 수의 비교는 아니다.
  실제 토큰량을 각각 기록하므로 결과는 이 구체적인 SFT 조건의 효과로 해석한다.
- 이번에는 학습 seed가 하나다. 생성 seed 다섯 개는 학습 seed 반복 실험을 대체하지 않는다.

## 평가와 실행 상태

외부 진단 5개는 별도 `evaluate.py`를 사용한다. 기존 CoT 문구·해상도·생성 파라미터를
사용하되, 이 외부 검사에서만 Answer 태그가 없으면 오답 처리한다. 공식 MMMU 결과와
혼동하지 않는다. 학습 19개에 대한 재추론은 적합 여부 확인용이며 일반화 성능이 아니다.

공식 결과는 **변경하지 않은 `run_eval.py`로 MMMU validation 900개 전체 × seed 0~4**를
두 SFT 모델에 모두 실행한다. 기존 base의 5개 결과와 비교한다. 중간 MMMU 결과로
문항·학습 설정·체크포인트를 선택하지 않는다. 전체 정확도가 주 지표이고 사전에 지정한
도표 유형의 변화는 보조 분석이다. 기존 평가 입력 처리에서 발견한 문제도 이번 비교 중
수정하지 않았으므로, 결과는 해당 기존 파이프라인에 대한 결과이다.

`compare.py`는 모든 seed의 설정, 900개 ID, 프롬프트, 정답, 과목별 30개를 검사한 뒤
평균 정확도 및 짝지은 문항 bootstrap 구간을 계산한다. 그 구간은 학습 seed 불확실성을
포함하지 않는다. 파일럿이 실패해도 SFT나 레이블링 전체가 효과 없다는 결론은 내리지 않는다.

실행 상태는 [runs/status.json](runs/status.json), 단계별 로그는 `runs/*.log`에 저장한다.
상태가 `complete`가 되기 전에는 전체 실험이 완료된 것이 아니다. 학습 가중치·이미지·
실행 중간 출력은 이 디렉터리의 `.gitignore`로 제외했다. 완료 후 `comparison.json`과
`reports/diagram_pilot_results.md`가 생성된다. 기존 기록상 공식 평가는 모델당 약 6.4시간이므로
두 조건을 순차 실행하면 학습·진단을 제외하고 약 13시간이 걸릴 수 있다.

```bash

  --source /tmp/bmmr_audit/bmmr-train-80k.jsonl \
  --images /tmp/bmmr_audit/pilot_images

# 데이터 혼입·변조 음성 대조군, 계산, 실제 processor의 손실 마스킹 검사
/home/leesg17/miniconda3/envs/vllm-train/bin/python pilot_diagram/checks.py

# solgyu-lee 브랜치에서 최초 한 번 실행. 기존/부분 결과를 조용히 재사용하지 않는다.
/home/leesg17/miniconda3/envs/vllm-train/bin/python pilot_diagram/run_pilot.py --launch
```

브랜치가 바뀌거나 단계가 실패하면 중단하며 실패한 단계와 로그를 남긴다.
