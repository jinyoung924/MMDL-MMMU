## 실제로 학습한 내용과 양

기존 SFT 어댑터를 이어 쓰지 않고 원래 Qwen3-VL-4B-Instruct와 고정된 초기 LoRA에서 출발했다. 승인된 TRAIN32(취약24·안정8)에만 R0 정답 보상을 적용했다. 선생 모델의 풀이를 새로 SFT하거나 R1 사실 검증 보상을 실행한 실험이 아니다. DEV 이미지·문제·독립 풀이·평가 응답은 학습에 추가하지 않았다.

학습 시드는0, 순서는 취약3:안정1, 문항당4응답, 예정32그룹·128응답, 응답당1024토큰으로 고정했다. 같은 문항을 다시 채우거나 중간 체크포인트를 골라 평가하지 않았다. 최종32그룹 체크포인트 하나만 평가했다.

**34/128은 변하는 학습 정책이 생성한 온라인 보상 수이며, 학습 후 정확도가 아니다.** 안정 TRAIN8도 학습 생성 조건과1024토큰 한도에서는 일부 미완료가 있었다. 이번 실행에서 취약24 중 정오 차이의 직접 policy-gradient 신호가 생긴 문항은10개였다. 이 신호량과 많은 길이 중단은 관측된 제약이지만, 각각을 바꾼 대조군이 없으므로 무개선의 단일 원인으로 확정하지 않는다.

보상은 정상 EOS로 종료하고 마지막에 단일한 정확한 `Answer: X`를 출력하며 TRAIN 정답과 일치하면1, 그 밖에는0이다. 길이 제한 응답은0점으로 포함하고 관측된 토큰 모두를 사용했다. 허위 EOS나 성공 응답 재충전은 없다. 학습의 엄격한 단일 최종 태그 규칙과, 기존 native 평가의 마지막 `Answer:` 태그 파서는 구분해 그대로 유지했다.

BASE·시각 인코더는 동결하고 언어 모델의7개 선형 모듈 LoRA만 학습했다. LoRA·Adam은FP32, 기반 모델은BF16, 학습률5e-6, KL계수0.04, PPO clip0.2, gradient clip1이다. 그룹 표본 표준편차와 고정 분모 `4×1024`를 사용했다. 고정 분모는 TRL의 dr_grpo 방식이며, 논문의 모든 통계적 성질을 입증했다는 뜻은 아니다.

실제 생성 시 기록한 행동 정책 μ를 PPO 비율의 분모로 사용했다. 전체 재계산된 full-old와 gradient forward의 일치 한계1e-5는 별도로 검사했다. KL에는 unclipped current/μ 비율을 적용했다. 관측된 행동 prefix에 대한 조건부 추정이며, 전체 trajectory의 정확한 on-policy gradient와 동등하다고 주장하지 않는다.
