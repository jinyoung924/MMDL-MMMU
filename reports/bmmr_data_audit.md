## 결론과 작업 범위

현재 브랜치 `solgyu-lee`에서 원본 데이터와 split 경계를 조사했다. BMMR은 실제로
학습용 `trainset/`과 평가용 `testset/`이 분리돼 있다. **학습 후보는 trainset의
JSONL에서만 추출한다. BMMR-Eval 및 MMMU validation은 중복 검사 대상이며 학습 입력이 아니다.**

전량 재레이블링보다 기존 풀이의 품질·언어를 검수하는 소규모 파일럿이 먼저다.

**52개도 학습 승인 상태가 아니다. 새 학습용 정답 생성과 SFT는 아직 하지 않았다.**

## 학습 파일의 실제 형식과 품질

학습 88,991행의 키는 모두 `id`, `conversations`, `image`다. 대화는 human 질문과
gpt 답변 각각 1개다. **별도 `answer`, `language`, `discipline`, `question_type` 필드는 없다.**
답변 끝의 선택지 글자는 기존 assistant 출력에서 추출한 참조값이지 독립적인 정답표가 아니다.

|---|---:|

| `### Reasoning Process ###` 포함 | 88,924 |
| `### Final answer ###` 포함 | 76,915 |
| 이미지 1개인 문항 | 85,960 |
| 이미지 참조 총수 / 고유 경로 | 93,000 / 79,820 |
| ZIP 목록에서 찾지 못한 참조 이미지 | 0 |
| 질문에 CJK 문자가 없는 문항 | 17,695 |
| 그중 답변에는 CJK 문자가 있는 문항 | 11,532 |

placeholder를 제거한 뒤 유의미한 영어 질문이 있는지 한 번 더 검사했다.

확인한 문제 사례:

- ID `69219068`: 질문 텍스트에 풀이 계산과 최종 수치가 이미 포함돼 있다. 그대로 쓰면
  이미지를 풀기보다 질문에 포함된 답을 복사하는 학습이 될 수 있다.
- ID `114691112`: 질문에 선택된 보기의 테두리를 설명하는 문구가 있다. 시각적 정답 힌트

구상 대신, **동일한 검수 정답으로 정답만 SFT vs 근거 풀이 SFT**를 먼저 비교한다.
실제 진행 상태와 결과는 해당 파일럿 기록을 기준으로 한다.

### 우선 표적: 전문 이미지 해석과 지식 적용의 연결

목표는 기존 CoT와 개선된 파서를 유지하면서 가장 큰 회수 가능한 오답 유형을 줄이는 것이다.
망각 지표는 이번 목적에서 제외한다. 기존 기준 성능은 5 seed 평균 64.93%이다.

[기존 실패 진단](../failure_diagnosis/README.md)의 48건은 과거 두 실행에서 모두 틀린
248건 중 추출한 표본이다. P(이미지 해석) 21건, G(생성 실패) 10건, K(지식) 8건,
D(문항 결함) 6건, T(텍스트 이해) 2건, PK 1건이다. 모델이 만든 진단이며 사람 검수 전이다.
따라서 P가 이 표본의 최대 유형이라는 관찰은 가능하지만, 현재 5 seed의 전체 오답에서
정확히 44%를 차지한다거나 시각 인코더가 정상이라는 결론은 낼 수 없다.

기존 주석에서 Biology_29는 말토스라는 지식은 맞지만 대응 구조식을 잘못 선택했고,
Basic_Medical_Science_13은 외안근의 신경 지배 지식은 맞지만 라벨이 가리키는 근육을
잘못 식별했다. 우선 가설은 **이미지의 위치·기호·관계를 전문 개념으로 해석하고,
그 해석에 맞는 지식을 적용하는 연결이 약하다**는 것이다. 지식 부족만으로 설명하지 않는다.

현재 52개는 입력·중복 검사 절차를 확인하기 위한 후보다. 직접 본 사례는 수학·그래프
문제가 많고 실패 능력에 맞춰 선정하지 않았다. 따라서 52개를 그대로 효과 검증용 학습
집합으로 확정하지 않는다. 원래 train 데이터에서 필요한 능력을 분류하고, 오답 규모와
양질의 train 예시 확보 가능성을 함께 보고 첫 표적을 선정한다. 평가 문제를 변형해
새 train 예시를 만드는 방식은 사용하지 않는다.

선택한 train 데이터에서도 학습용과 진단용을 이미지·출처 단위로 분리한다. 진단용에서는
원래 입력 / 정확한 시각 설명 추가 / 관련 지식 추가 / 둘 다 추가 조건을 비교하여
어떤 정보가 정답 회복에 도움이 되는지 조사할 수 있다. 이는 공식 평가와 별도의 가설
검증이며, 프롬프트 변화도 포함되므로 인코더 내부의 원인을 단독으로 입증하지는 않는다.
진단용 문항과 설명도 SFT 입력에서 제외한다.

### 학습 및 평가 비교

1. 유사 이미지 보류 7개는 학습 후보에서 계속 제외한다. 기존 52개 및 추가로 선별할
   train 후보에서 표적 능력 적합성, 질문 완전성, 보기·이미지 일치, 정답 힌트 노출,
   출처 중복을 검수한다. 추가 후보에도 동일한 평가 데이터 중복 검사를 적용한다.
2. 통과한 train 문항만 정답·기존 풀이를 숨긴 채 교사에게 풀게 한다. 이미지 근거와
   전문 개념의 대응, 적용 규칙과 그 조건, 짧은 검증 가능한 풀이, `Answer: X`를 생성한다.
   답이 맞더라도 이미지에 없는 근거를 지어낸 풀이는 통과시키지 않는다. 이후 기존 답변과
   비교하되, 기존 답변을 절대 정답으로 취급하지 않는다. 불일치는 재검수로 보낸다.
3. 학습 예시에 원본 ID·revision·split·이미지 해시·주석 버전·검수 상태를 보존한다.
   평가 문항에서 파생한 이미지·질문·답·풀이를 학습 예시로 전환하지 않는다.
4. 주석 파일럿이 유효하면 동일한 train 문항 집합으로 **기존 풀이 SFT vs 새 검증 풀이 SFT**를
   비교한다. 기본 모델도 함께 평가한다. 기존 데이터에 이미 풀이가 있으므로 이 비교가
   '새 레이블링의 추가 가치'를 직접 묻는다. 정답만 SFT는 필요할 때 별도 대조군으로 둔다.
5. 출발 모델과 학습 설정을 맞추고 출력 길이에 따른 학습 토큰량도 기록한다. 영어 출력으로의
   변경과 풀이 내용 개선을 동시에 바꾸면 효과가 섞이므로, 결과를 해석할 때 둘을 구분한다.
6. 학생 모델 평가는 기존 CoT·개선 파서·생성 설정과 900문항 전체, 동일한 5 seed로 수행한다.
   주 지표는 전체 정확도 변화이며 표적 유형의 개선은 보조 분석으로 보고한다. 이 조사에서는
   `run_eval.py`, `eval.sh`, `analyze.py` 및 베이스라인 결과를 변경하지 않았다.
