# 망각 파일럿 — 사전 등록 (2026-09-25, 결과를 보기 전에 작성)

## 질문

실패 진단에서 가장 약했던 도메인(병리 이미지)을 겨냥해 **표준 방식(데이터셋 정답으로 SFT)**으로 fine-tuning하면,
모델이 원래 잘하던 MMMU 능력을 **실제로 잃는가?**

전략 문서는 "약점을 고치는 fine-tuning은 망각을 일으킨다"는 전제 위에 서므로, 이 전제를 우리 모델과 설정에서 직접 확인합니다.
문헌(Luo et al. 2026: Qwen3-VL-4B에서 LoRA-SFT가 MMMU-Pro −11.5점)은 5개 과제를 순차 학습한 다른 설정이라 대신할 수 없습니다.

## 설계

| 항목 | 값 |
|---|---|
| 모델 | `Qwen/Qwen3-VL-4B-Instruct` @ `ebb281ec` (평가와 같은 revision) |
| 학습 | LoRA r=16, α=32, dropout 0.05, 언어 모델의 q/k/v/o/gate/up/down 투영만. 비전 인코더·merger 고정. bf16, AdamW lr 1e-4, warmup 50, grad clip 1.0, batch 4 × accum 2, 2000 스텝, seed 0 |
| 학습 데이터 (외부 정답) | PathVQA (`flaviagiammarino/path-vqa` @ `16858328`) train의 yes/no 문항. 프롬프트 = 질문 + "Answer with yes or no.", 정답 = 데이터셋의 답 |
| 학습 지시문 | MMMU의 CoT 지시문과 **일부러 다르게** 둠. 학습 뒤 MMMU에서 풀이 행동이 달라지면 지시문이 섞인 탓이 아니라 망각 |
| 체크포인트 | 250, 1000, 2000 스텝 (어댑터 저장 → 전체 가중치로 병합해 평가) |
| 표적 향상 | PathVQA test yes/no 500문항(고정 무작위 표본), greedy 정확도 |
| 망각 측정 | 고정된 MMMU 파이프라인(`run_eval.py` 기본값, 결정적 모드) 900문항. 2000 스텝은 seed 0·1, 250·1000 스텝은 seed 0 |
| 비교 기준 | 공식 base 실행 `results/seed0..4`. 같은 seed끼리, 같은 문항끼리 짝 비교(`analyze.py compare`) |
| 표적 과목 (망각 판정에서 제외) | Basic_Medical_Science, Clinical_Medicine, Diagnostics_and_Laboratory_Medicine, Pharmacy, Public_Health |

## 판정 기준 (사전 등록)

- **주 지표**: 2000 스텝 체크포인트에서 **비표적 25과목(750문항)의 정확도 변화 Δ**. seed 0·1 짝 비교, 문항 부트스트랩 95% 신뢰구간.
- **판정**:
  - PathVQA 정확도가 base보다 5점 이상 올랐고 Δ의 신뢰구간이 전부 0보다 작으면 → **망각 확인**.
  - 신뢰구간이 0을 포함하면 → **"이 설정(LoRA r=16, lr 1e-4, 2000 스텝)에서는 검출되지 않음"을 그대로 결과로 보고**합니다.
    결과를 보고 설정을 바꿔 다시 돌려 "망각"을 만들어내지 않습니다. 더 강한 학습 설정을 추가로 돌린다면 별도 실험으로 명시해 보고합니다.
  - PathVQA가 5점 이상 오르지 않으면 → 적응 자체가 없었으므로 망각을 판정할 수 없음으로 보고합니다.
- **기술 통계** (판정에는 쓰지 않음): 체크포인트별 Δ(seed 0), 표적 과목 Δ, base가 안정적으로 맞히던 문항 중 잃은 수(base 노이즈 바닥과 비교),
  잃은 문항의 형식/내용 분해(잘림·태그 없음 vs 끝까지 풀고 틀림), 잘림 비율·태그 비율·응답 길이.

## 측정 설계에서 미리 확인한 함정 (base 대 base 귀무 비교)

같은 모델의 서로 다른 실행을 비교해 도구를 검증했습니다(`ablation/cot_8192_seed0_run2`·`seed1` vs `run1`).

- **선택 편향**: "base가 맞힌 문항"을 비교에 쓰는 실행으로 고르면, 모델이 바뀌지 않았는데도 **−9.7점 [−12.8, −7.1]**의 "망각"이 나왔습니다.
  평균으로의 회귀 때문입니다. 그래서 안정 정답은 **비교에 쓰지 않는 seed(2·3·4)**로만 고릅니다. 이렇게 고치면 −0.8점 [−4.2, +2.4]입니다.
- **다중 비교**: 같은 귀무 비교에서 150문항 하위 그룹이 우연히 신뢰구간 0 밖(+6.7 [+0.7, +12.7])으로 나왔습니다.
  그래서 판정에는 **주 지표 하나만** 씁니다.

## 한계

- 외부 정답 SFT 한 가지(답만 학습)입니다. 풀이를 포함한 정답 형식, 자기 생성 정답(반복형 RAFT), GRPO의 비교는 다음 단계(정답 출처 가설의 VLM 확장)입니다.
  답이 한 단어("yes/no")인 과제에서는 자기 생성 정답과 외부 정답이 같은 토큰이 되므로, 출처 비교에는 풀이를 포함한 형식이 필요합니다.
- 망각은 MMMU 안에서만 잽니다. MMMU 밖의 능력(일반 VQA, 텍스트 추론)은 재지 않습니다.
- 학습 seed가 1개입니다.

## 실행

```bash
# 학습 환경: 평가 환경(vllm)을 복제하고 peft·accelerate만 --no-deps로 추가 (평가 환경은 건드리지 않음)
conda create -n vllm-train --clone vllm && conda run -n vllm-train pip install --no-deps peft accelerate

R=pilot_forgetting/runs/sft_lr1e-4
conda run -n vllm-train python pilot_forgetting/train_sft.py --out $R                 # 학습 + PathVQA 평가 + 어댑터 저장
conda run -n vllm-train python pilot_forgetting/train_sft.py --merge $R/step2000     # → $R/step2000_merged/
python run_eval.py --model $PWD/$R/step2000_merged --seed 0 --out pilot_forgetting/eval/step2000/seed0   # 평가 환경
python run_eval.py --model $PWD/$R/step2000_merged --seed 1 --out pilot_forgetting/eval/step2000/seed1
python analyze.py compare results/seed{0,1,2,3,4} vs pilot_forgetting/eval/step2000/seed{0,1} \
    --target "Basic_Medical_Science,Clinical_Medicine,Diagnostics_and_Laboratory_Medicine,Pharmacy,Public_Health"
```

## 결과 (2026-09-26 12:19 기록, 사전 등록 기준대로)

**표적 향상**: PathVQA test yes/no 500문항 정확도 70.6% → 87.8%(250) → 91.6%(1000) → **91.8%(2000)**. +21.2점으로
"5점 이상" 조건을 충족했습니다.

**주 지표 판정** (2000 스텝, seed 0·1 짝 비교, `analyze.py compare` 출력은 `compare_step2000.txt`):

| 지표 | Δ | 95% CI | 비고 |
|---|---|---|---|
| **비표적 25과목 750문항 (주 지표)** | **−2.27점** | **[−4.73, +0.20]** | **0을 포함 → 사전 등록 기준 미달. "이 설정에서는 검출되지 않음"** |
| 비표적 중 base 안정 정답 385문항 (seed 2·3·4로 선택) | −5.19점 | [−7.79, −2.60] | 기술 통계 |
| 표적 과목 150문항 (MMMU 의학 5과목) | −6.00점 | [−11.00, −0.67] | 기술 통계 |
| 전체 900문항 | −2.89점 | [−5.06, −0.67] | 기술 통계 |

- seed별 종합: seed 0 64.33 → 64.11, seed 1 66.56 → 61.00.
- base 안정 정답 385문항 중 seed 0·1 모두 오답: base 3개(노이즈 바닥) vs fine-tuning 22개
  (형식 붕괴 5개, 끝까지 풀고 틀림 17개).
- 행동 변화: 평균 응답 길이 7,543자 → 5,467자(−28%), 잘림 14.8% → 12.2%, `Answer:` 태그 85.3% → 87.7%.

**해석** (판정은 바꾸지 않음):
1. 사전 등록한 주 지표로는 망각이 **확인되지 않았습니다**(상한 +0.20, 경계선).
2. 주 지표는 비표적 과목의 **순변화**라 손실과 이득이 상쇄됩니다. 응답이 짧아져 잘림이 줄면서 생긴 이득이
   손실을 가렸을 가능성이 있습니다. base가 확실히 풀던 문항만 보면 손실이 뚜렷하지만(22 vs 3), 이 지표는
   사전 등록에서 기술 통계로 정했으므로 강한 신호로만 보고합니다.
3. 표적 향상(+21점)이 MMMU 의학 과목으로 옮겨가지 않았고 오히려 −6점이었습니다. yes/no 한 단어 정답으로 학습해
   풀이가 짧아진 것이 다단계 진단 추론을 해쳤을 가능성이 있습니다.
4. 교훈: 다음 확인 실험(정답 출처 비교)은 **"base 안정 정답의 손실(선택 seed와 측정 seed 분리)"과 "비표적 순변화"를
   처음부터 함께 주 지표로 사전 등록**합니다. 이미 결과를 본 이 파일럿에 seed를 추가해 판정을 바꾸지는 않습니다.

**추가 기술 통계** (판정에는 쓰지 않음):
- 주 지표를 seed별로 나누면 seed 0 **+0.40**, seed 1 **−4.93**점입니다. 문항 부트스트랩(10,000회) 양측 p ≈ **0.07**.
  비표적 750문항 중 나빠진 문항 119개, 좋아진 문항 96개입니다.
- 행동 변화가 가장 뚜렷합니다. MMMU 응답 1,800개(2 seed × 900) 중 **82%가 짧아졌고**, 길이 비율의 중앙값은 **0.69**입니다.
  학습 지시문("Answer with yes or no.")을 MMMU의 CoT 지시문과 다르게 두었는데도 짧게 답하는 습관이 번졌습니다.
- base 안정 정답에서 잃은 22문항은 특정 과목에 몰리지 않고(최다 Physics 3개) 여러 이미지 유형(Diagrams 7, Tables 5,
  Plots and Charts 4)과 난이도(Easy 7, Medium 10, Hard 5)에 퍼져 있습니다. 특정 지식보다 전반적 능력의 손실에 가깝습니다.
